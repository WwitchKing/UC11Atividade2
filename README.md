# 🛒 Projeto LeiloesTDS - Atividade 02/UC11 SENAC

Sistema desktop desenvolvido em **Java** para gerenciamento de produtos e controle de vendas.

## ✨ Funcionalidades

* 📦 Cadastro de produtos
* 📋 Listagem de produtos
* 🔎 Consulta de produtos
* 💰 Registro de vendas
* 🛍️ Listagem de produtos vendidos
* 🧮 Cálculo do valor total das vendas

## 🛠️ Tecnologias utilizadas

* ☕ Java
* 🗄️ MySQL
  
## 📂 Estrutura do Projeto


LeiloesTDSat
│
├── ProdutosDAO.java
├── ProdutosDTO.java
├── conectaDAO.java
├── cadastroVIEW.java
├── listagemVIEW.java
└── vendasVIEW.java

## 🖼️ Telas do sistema

O sistema possui telas para:

* 📦 Cadastro de produtos
* 📋 Listagem de produtos
* 💵 Vendas
* 🛒 Produtos vendidos


Projeto desenvolvido para fins acadêmicos e de aprendizado.
